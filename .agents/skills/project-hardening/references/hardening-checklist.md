# Hardening checklist

- AGENTS hierarchy and size; on-request approvals; no danger-full-access.
- Read-only/workspace permissions, network deny, login shell off and secret filtering.
- `.rules`, admin requirements and protected-path read denials.
- MCP identity, tool allowlist, approval mode, pin and drift.
- Skill/plugin provenance and dependency installs.
- Backend identity, tenant, record authorization and approvals.
- RAG source authorization and injection filtering.
- SAST, SCA, secret, IaC, container scans and SBOM.
- Traces, redaction, alerts, kill switch, incident response, canary, rollback and reconciliation.
