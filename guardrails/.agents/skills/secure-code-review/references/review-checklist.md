# Review checklist

- Authentication and session handling.
- Authorization by object and tenant; fail-closed behavior.
- Input validation and output encoding.
- SQL, shell, template, command and deserialization injection.
- SSRF, path traversal, XSS, CSRF and uploads.
- Secrets, PII, logs and retention.
- Crypto and key management.
- Network destinations and egress.
- Tool/MCP schemas, approvals and prompt injection.
- Idempotency, transactions, retries, timeouts and partial side effects.
- Dependency, lockfile, install scripts and license risk.
- Breaking APIs, events, schemas, persisted formats and CLI behavior.
- Tests removed, weakened, skipped or falsely reported.
